REASON: Most lines are short, clear and useful, with distinct voices and no forbidden words, unsupported names or length violations. Keeping every item is justified: each can communicate a meaningful sighting. The main failure is treating detection and hostility as arrest or detention. Several lines invent that outcome, and the Enforcer's enemy line reads like an explanation of the rules.

  • TRUE takedown-seen/guard “You there! You're under arrest!”: The event establishes detection, an immediate alarm and hostility toward the Enforcer. It does not establish an arrest.
    Fix: Use "You there! Sound the alarm!"
  • TRUE takedown-seen/guard “Raise the alarm! You're not leaving!”: You're not leaving promises that escape will be prevented; the event guarantees no such outcome.
    Fix: Use "Raise the alarm! Stay where you are!"
  • TRUE takedown-seen/patrol “Assistance required. Citizen, please remain for arrest.”: The event does not establish that the patrol will arrest anyone.
    Fix: Use "Assistance required. Citizen, please remain still."
  • PLAIN takedown-seen/patrol “Citizen, please remain for arrest.”: Remain for arrest is awkward administrative wording, even for the patrol's fixed polite commands.
    Fix: Use "Citizen, please remain still."
  • TRUE takedown-seen/patrol “Please remain still. You are under arrest.”: Becoming a foe does not establish an arrest.
    Fix: Use "Please remain still. Assistance has been requested." only if that request is guaranteed; otherwise use "Please remain still. Assistance required."
  • TRUE takedown-seen/patrol “Citizen, you are being detained. Please cooperate.”: The event does not establish detention in progress.
    Fix: Use "Citizen, stop where you are. Please cooperate."
  • TRUE takedown-seen/security “Someone's down. Move in for arrest.”: The arrest instruction adds a specific response not supplied by this event.
    Fix: Use "Someone's down. Watch the one responsible."
  • TRUE takedown-seen/security “Person down. Detain the one responsible.”: The event establishes hostility, but does not establish an order to detain.
    Fix: Use "Person down. Eyes on the one responsible."
  • TRUE takedown-seen/security “Someone's hurt. Make the arrest.”: Neither an injury nor an arrest instruction is guaranteed by seeing a takedown or a carried body.
    Fix: Use "Someone's down. Watch who did it."
  • VOICE takedown-seen/enforcer “I'm their enemy now.”: This explains the foe state to the player instead of sounding like the Enforcer's dry, terse reaction.
    Fix: Use "That'll mean trouble."
