First draft · SCORE 8/10

REASON: The acknowledgements convey useful orders, fit both length limits, use plain language and correct names, and suit the Tech's practical voice. All items correctly remain uncut. A few variants invent timing, broaden detection guarantees or change the ordered action.

  • TRUE ack/loop/tech “I'll make the camera repeat two minutes.”: Two minutes is how long the loop runs, not the length of footage repeated.
    Fix: I'll make the camera repeat pictures for two minutes.
  • TRUE ack/run/tech “anyone watching will notice”: The facts say watchers notice running; this broadens that to guaranteed detection by anyone watching.
    Fix: I'll run there; watchers notice running.
  • TRUE ack/stash/tech “I'll find a hiding place for the body.”: The order hides the carried body in a bin or behind a service door. It does not establish a search for a hiding place.
    Fix: I'll hide the body where you've ordered.
  • TRUE ack/restrain/tech “before they wake”: The person is unconscious, but the facts do not guarantee that tying finishes before they wake.
    Fix: I'll secure them where they're lying.
