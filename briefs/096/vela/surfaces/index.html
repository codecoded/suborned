Item 5 · the matte enamels move to the Lit copy

K2 turned the clear coat off (keyword off, mask 0). Without _CLEARCOAT, Complex Lit runs the same BRDF as Lit, so only the shader guid changes. to_lit() asserts that no clear-coated .mat moves. Every moved kit enamel has _ClearCoatMask: 0, so the Lit copy's reflection scale (1 − mask) is unchanged and reflections stay off. There is no in-player before/after: the review switch can't swap a shader. The pixel diff belongs to Latch's regenerated build (done-check below).
