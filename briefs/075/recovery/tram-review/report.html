Code assessment and limits

The geometric subtraction is structurally sound for the current unit-scale, yaw-only 2×2 tiles: SwapShapes.Convex supplies counterclockwise footprints, each successive inside-plane plus its opposite outside plane partitions the convex polygon complement, then repeated subtraction takes the union of tile footprints. Interpolated local/world vertices retain normals, tangents, UV0/UV1 and colours through SwapMesh; UInt32 indices are selected when needed. There is no source mesh mutation: Write constructs a new Mesh and only MeshFilter.sharedMesh is reassigned; no collider assignment occurs in this increment.

The numerical boundary issue above prevents claiming mathematically exact seam handling. SAT uses 1e-4 projection tolerance while Clip uses zero tolerance; the audit allows 1 mm at tile edges. No images or 1 m sampling sweep proves sub-millimetre seam freedom. Tile footprints ignore scale and tilt and the height condition is a triangle-bounds candidate band, not a vertical clip. Those assumptions fit the current builder, which places fixed tiles at BedLift=.005, but do not authorize arbitrary scaled tiles or tall/sloped granite meshes. Nontriangle topology and attributes beyond the helper's supported set are not preserved by a rewritten mixed mesh; no such current output was established. Unreadable imported correction meshes are silently skipped at :194; future coverage should remain explicit rather than assuming the audit reader also fixes them.

V2's editor MeshUtility.AcquireReadOnlyMeshData bypasses runtime readability without importer changes. MeshDataArray, vertex NativeArray and each index NativeArray are scoped with using; managed copies outlive disposal, and exception unwinding disposes acquired buffers. GetIndices applies the submesh base vertex by default; nontriangle submeshes are excluded. Failed reads become named coverage warnings, never bounds faces. The reader includes downward-facing near-horizontal triangles, which correctly explains expected Tram/DK_Iron underside occupancy (234 triangle hits across the residual over set). Those are not ground failures. The reader covers active MeshRenderers near sampled street positions with lower LODs excluded; it is not a visibility, skinned-mesh, whole-scene or gameplay acceptance test.

Source integration is default-on for OldTownSwap.Build: ClearImportedGround follows SwapCut and precedes final merge/audit. TramFix calls the same function on the saved scene and persists eight render mesh assets. No opt-in switch is required to get the correction in the normal builder. The controlled saved-scene run proves that path only; a fresh full builder was not run in this review. The broader pre-existing Swap bundle compiles together, including untracked SwapKeep.cs and SwapTramAudit.cs; that does not approve its keep/drop, HQ, road lift, material or world behavior.
