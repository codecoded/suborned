Contract

  • Build(orderedRoute, unorderedTiles, closed, width=2, tolerance=.002) takes one identified track at a time. Each tile carries centre, tangent and actual exported subdivision step. IDs never select neighbours. Geometric nearest projection onto ordered route stations sorts tiles; ambiguous nonlocal projections and duplicate stations reject. Caller must partition route/track membership, not mix intersecting routes or both parallel tracks. The harness derives membership from export edge and signed distance, then offsets the transit polyline by its actual track spacing.
  • For each neighbour, intersect corresponding left and right infinite tangent-band edges at the unchanged half-width. Both footprints reference the same Seam object and vertices. Parallel coincident lines use the midpoint of nominal interval endpoints as the perpendicular common seam. Open endpoints use actual step/2 caps; closed tracks share the closing seam. No fixed-2m length, per-sample exception, widening or longitudinal padding is used.
  • Result Footprint supplies Source, oriented Direction/Normal, Start/End seam, CCW Polygon and Contains. This is the one polygon contract for future mesh ownership, Bed/ClearBed and audit. Seam.At interpolates any transverse location, including each rail web/head/keeper/groove vertex.
  • Map(along,lateral) takes original tile along coordinate [-1,1] and lateral metres. It alters only distance along the original tangent; lateral coordinate is unchanged and along=0 is fixed for every cross-section. The consumer must copy each vertex's vertical coordinate unchanged. Source height is deliberately absent from this plan-frame helper. The source's 0.4625m gauge faces and ±0.5m rail-head centres require no scaling. The helper neither changes gauge nor proves final rail mesh continuity.
  • Map is piecewise affine about along=0. Mesh triangles crossing that plane must be split before mapping, with interpolated attributes. Existing source submeshes, transverse/height profiles and material boundaries must remain. UV density, normals/tangents, end caps and float conversion need explicit integration validation.
  • Zero-length route edges/tangents, nonfinite coordinates/steps, route or tile turns ≥90°, displaced parallel tangents, nonadjacent intervals, ambiguous ordering and folded/nonconvex/spiking mitres reject with ArgumentException. Near-parallel spikes are rejected, never capped into fabricated geometry. Supported turns are explicitly below 90°. Tolerance controls input validation only; no polygon grows by it.

Open issues — explicit export rejections

188 rejected boundaries: 178 displaced-parallel tangent pairs (e.g. rail-29#5 → rail-30#0, transverse offset 0.044078mm), and ten nonadjacent/missing-interval boundaries in T1/loop. Export rounding makes some nominally continuous straight centreline bands strictly distinct parallel lines. One full-width seam cannot lie on both original bands simultaneously. Silently snapping their centres, widening, or accepting microscopic overlaps would violate this phase's strict contract.

The harness partitions at these explicit rejections to test the remaining supported joins. It does not treat a rejection as a solved seam: the new open caps at those boundaries are only test-run boundaries. The entire pinned track Build intentionally rejects if fed unchanged as one chain. Synthetic closed-loop coverage passes; the export loop's disconnected/missing intervals still require topology validation. No production resolver or geometry mutation is hidden in the harness.

Aster/Splice must establish authoritative unrounded per-track tangent geometry or explicitly approve a centreline quantisation reconciliation rule before those parallel joins can be hooked up. For missing intervals, establish genuine disconnected/open runs from topology rather than bridging a gap or silently splitting around a failed join. This helper must not be used to make those decisions by tile ID.
