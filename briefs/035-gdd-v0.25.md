**Why the drafts are in `GDD/draft/`:** `tools/missions/handover/mission.test.ts` expects exactly one agent GDD in `GDD/`. Also, `bun run crew`, the RAG corpus and the art bible generator all pick the newest file there. A v0.25 file in `GDD/` would break the tests and make the crew read an unapproved draft.

## How the GDD reads now

- **Present tense only.** There are no version lines at the top, no dated decisions in §12, no "(Sky, date)" inside sections, and no "was / since / replaces".
- **Provenance** lives in the decision log, the briefs and git.
- **Sky's quotes** are now plain design statements. Example: "if you're not seen then everyone assumes you're good" becomes "if nobody sees you, the city assumes you are good".
- **New tag, [lab]:** a playground or fight-lab switch. It is in the build so you can try it, but it isn't the game until you promote it.
  - A house rule in §01 says so.
  - The engine already works this way: a lab rule is off unless a run turns it on, and with it off every replay is unchanged.
- **Items left as [lab]:** the ground view, explore, the camera lab, the fight lab and the fight range.
