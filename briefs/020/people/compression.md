# People: every compressed model (source -> shipped)

Brief 020, Forma, 2026-10-20. For Sky's review: compression goes through Sky, so nothing new is decimated or downscaled without her. Everything below already exists and stays for now.
Source = the glb the LOD came from (triangles; largest image side). Shipped = the FBX (triangles) and the albedo jpg/png in `Figures/<id>/Textures` (largest side, measured). "Decimated" = a Blender decimate in `tools/figures/build.py`; "own file" = a source glb used as it is. Textures shipped at 2048 / 1024 / 512 are named for the target; where the measured side differs the source was smaller (it is never upscaled).

Generated by `tools/figures/scratch/compression_audit.py`.

## Addendum, 2026-10-20: the cell from the testbed (`out/people-models/CellGeneric`, not yet in the game)

Nothing here is compressed by us. scout, tech and enforcer come from the uncompressed originals the testbed's web glbs were made from; the fixer is her existing build re-exported.

| Figure | LOD | Source | Tris in source | Tris shipped | Textures (largest side) | Change |
|---|---|---|---|---|---|---|
| scout | LOD0 / LOD1 / LOD2 | `scout_lod/scout_S1-2_LOD0_30k`, `LOD1_12k`, `LOD2_4k5` | 29,148 / 12,000 / 4,500 | same | 2048 / 2048 / 1024 | none; image bytes copied from the glb |
| tech | LOD0 / LOD1 / LOD2 | `tech_lod/tech_F2-1_LOD0_30k`, `LOD1_12k`, `LOD2_4k5` (body + visor sheet) | 33,628 / 14,999 / 6,999 | same | 2048 / 2048 / 1024 (visor 1024) | none |
| enforcer | LOD0 only | `characters/enforcer_G2/07_export/enforcer_G2.2k.glb` | 28,796 | same | 2048 PNG | none (the Humanoid build decimated this to 12k/4.5k/1.5k; the new one does not) |
| fixer | LOD0 / LOD1 / LOD2 | unchanged from the Humanoid build above | 28,428 -> 12k / 4.5k / 1.5k | same as before | same as before | none new |

Not mesh or texture compression, but listed so Sky sees all of it: Unity applies its own GPU texture compression when it imports any texture (the importer default; it is that way for the whole game). The previous build also re-encoded big PNG albedo and normal maps to JPEG q90 and baked an ORM-derived metal map; the new cell materials use the glb's albedo and normal bytes as they are, with no metal map (matte, per Glint). FBX animation keys are written at every frame, uncompressed (the files are 22 to 65 MB each).
