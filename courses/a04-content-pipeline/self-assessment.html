Self-assessment · A04 content pipeline (run r006)

Submitted run: runs/levels/harbour-district/r006/, ACCEPTED in 3 rounds. It ran on GDD v0.15.0, the Oct 9 civic block (café 22 × 11.3 × 34.8 m, rule C-0) and the plan with the Skyport Pier. The five runs before it are kept as evidence. Each found a defect, and each defect was fixed before the next run.

What the pipeline does well

  • Game-specific. The outputs are edits to the district plan that the Unity graybox is derived from. They are judged by the same plan checker that gates every plan. The GDD rule "no AI at runtime, exact replay" holds: bun run levels:replay r006 rebuilds every round from committed data, without Docker or a model. That includes the derived timetable.
  • Models decide; code computes and checks. In r006 each kind of work went to whoever does it best:
    • Datum chose to add a T3 Sunset Line;
    • Vantage placed the stops;
    • Pulse chose speeds, dwells, headways and routes;
    • code derived every run time and journey total;
    • code checked citations and walk access;
    • Keel judged what no rule can.
    r006 recorded 0 citation faults and 0 timetable faults.
  • Owners talk through the loop. In round 1, Vantage told Datum that N-R1 couldn't pass on the current lines, and Datum asked Vantage for T2 interchanges. Both blocking hand-offs became faults for their owners. In round 2 Keel passed, but Datum's ask for T3 stops was still open, so the run went to round 3 rather than accepting a network with an unstopped line.
  • The Skyport gap is closed. Runs r001–r005 could not place a Skyport station because nobody could walk to it. Datum planned a pier and apron. In r006, Vantage placed S1 Skyport there, and rule W-2 confirms every station can be reached on foot.
  • Replay explains drift instead of hiding it. Runs pin their block and record their GDD version. Replay labels drift by cause: superseded: recorded against the Oct 5 block, recorded against GDD v0.14.0, checker rules added since the run: W-2, W-3; this plan would FAIL W-2, W-3. A changed result on a rule the run recorded is still a FAIL.
