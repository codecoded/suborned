ASSIGNMENT 7 / COMPLETE AI DEV PIPELINE

The Suborned

Sky Rumsey | Unity | From game design to a playable release

The Suborned is squad tactics built around social infiltration. AI assists development and content creation; no AI model runs during play.

1. From design to game

Design / agent work / review / Unity / tests / release. The game-design document sets the rules. Specialist agents work from focused briefs and retrieve relevant design passages for structured generation. They propose code and content; automated checks and agent reviews catch faults. I approve design and creative choices.

Outputs include world geometry and props, character art, people and routines, dialogue, simulation code and the interface. Approved plans and asset lists drive generation and import. Checked data feeds Unity; builds are playtested, packaged, signed and published.

The video's worked example: cast data becomes 130 people and 222 relationship links, is exported automatically, and functions in Unity without hand reformatting. Inez's debt and relationship with Arthur give the player a way past his post.

Human work remains: design, art selection and finishing, dialogue revision, playtesting and release approval. To automate more, I would store approved choices as data and connect the remaining steps from checks through publishing.

2. What I would change

Give each release one complete, versioned build record. Individual approvals do not preserve every dependency: the mission cast matches the shipped game, but the redesigned city changes some background residents and travel stops when regenerated.

I would save the design, city plan, rules, assets and generator versions together. Builds would regenerate changed outputs and reject mismatched inputs.

3. Actual costs, with a clear boundary

The people run used $0.6905 across three AI calls, including a rejected proposal. Its largest call was the Claude Opus review, about $0.28; Claude Sonnet drafted the cast. These are subscription usage values, not extra API payments.

Separately, portraits incurred $1.1556 in image API charges. Neither figure is the game's total cost; project-wide spend has not been reconciled. Subscription fees, labour, hardware and hosting are excluded.

Reuse and spending limits make these examples affordable for solo development. Review still costs time.

4. A cost-saving change to the shared workflow

Before: the AI reviewer ran even when code had already found a fault. Two such reviews in an earlier transit run used about $0.41. After: failed checks go straight back for correction. The people run's failed first round therefore used zero review calls, zero review tokens and $0 review cost. The corrected result still received review. Different candidates mean no like-for-like percentage saving is claimed.
